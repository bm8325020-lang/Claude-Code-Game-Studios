# Engenharia reversa — regras e método
Objetivo: base de conhecimento para DEAD DISTRICT. Estudar como funciona; NUNCA copiar código, modelos, texturas, sons.
Tipos: A técnica (arquivos), B visual/comportamental (vídeo, documentação, palestras), C híbrida, D baixa prioridade.
Só tipo A com arquivo LEGÍTIMO: código aberto (licença respeitada) ou cópia comprada pelo dono no aparelho dele.
Não baixar APK/executável de site de terceiros. Não mexer em servidor, login, pagamento, anti-trapaça.
Evidência: FATO OBSERVADO / INFERÊNCIA TÉCNICA / HIPÓTESE / NÃO CONFIRMADO, com fonte, timestamp e confiança.
Descoberta: APROVEITAR / ADAPTAR / INVESTIGAR / DESCARTAR, com viabilidade em Godot 4 e impacto no Android.
Relatório: modelo em RELATORIOS/_MODELO.md.
